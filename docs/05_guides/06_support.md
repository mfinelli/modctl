# Support & troubleshooting

If you run into a problem with modctl or have a question that isn't answered
by the documentation, the best place to go is GitHub.

- **Bug reports and unexpected behavior:** open an issue on the
  [issue tracker](https://github.com/mfinelli/modctl/issues). Include the
  output of `modctl --version` and any relevant error messages.
- **Questions and general discussion:** start a thread in
  [GitHub Discussions](https://github.com/mfinelli/modctl/discussions).

This page will be expanded with common issues and solutions as they are
reported by users.
